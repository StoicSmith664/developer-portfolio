# Award-Winning Developer Portfolio

A stunning, award-winning developer portfolio built with React, Framer Motion, Tailwind CSS, and Three.js.

## 🌟 Features

- ✅ **Smooth Animations** - Framer Motion animations throughout
- ✅ **Mouse Effects** - Custom cursor effect that follows mouse movement
- ✅ **Smooth Scrolling** - React Scroll for seamless navigation
- ✅ **3D Models** - Three.js integration for 3D graphics
- ✅ **Theme Switcher** - Dark/Light mode toggle
- ✅ **SEO Optimized** - Meta tags and semantic HTML
- ✅ **Fast Loading** - Optimized performance and lazy loading
- ✅ **Mobile Responsive** - Works perfectly on all devices
- ✅ **Glass Morphism** - Modern UI with glassmorphic effects
- ✅ **Gradient UI** - Beautiful gradient backgrounds and text

## 📋 Sections

1. **Hero** - Eye-catching landing section
2. **About** - Personal introduction
3. **Skills** - Technical skills showcase
4. **Experience** - Work history timeline
5. **Projects** - Featured portfolio projects
6. **Testimonials** - Client testimonials
7. **Blog** - Latest articles
8. **Contact** - Contact form and social links

## 🚀 Getting Started

### Prerequisites
- Node.js 16+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/StoicSmith664/developer-portfolio.git

# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build
```

## 🛠 Tech Stack

- **Frontend Framework**: React 18
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **3D Graphics**: Three.js
- **State Management**: Zustand
- **Navigation**: React Scroll
- **Icons**: Lucide React
- **Language**: TypeScript

## 🎨 Customization

### Update Theme Colors

Edit `tailwind.config.js`:

```javascript
colors: {
  accent: '#8b5cf6',
  'accent-secondary': '#ec4899',
  'accent-tertiary': '#06b6d4',
}
```

### Update Content

Edit the section components in `src/components/sections/` to add your own:
- Personal information
- Project links
- Social media links
- Blog posts
- Testimonials
